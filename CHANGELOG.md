# Changelog

All notable changes to Amicro Vue are documented in this file.

## [1.0.0] - 2026-07-20

### Added

- Vue 3 and TypeScript implementation of the Amicro micro-transition catalog.
- 35 configurable button micro-interactions.
- Data-driven card spread demonstrations.
- Interactive 3D carousel demonstrations.
- Dark and light themes.
- Responsive list, grid, and matrix layouts.
- Hash-based component and motion-guide pages.
- Copyable Vue single-file component examples.
- Motion accessibility through `prefers-reduced-motion` support.
- GitHub Actions validation for type checking and production builds.

### Changed

- Replaced the React implementation with Vue Composition API components.
- Replaced `motion/react` with Motion for Vue through `motion-v`.
- Replaced Tailwind-dependent runtime styling with project-owned CSS variables and component styles.
- Consolidated repeated card layouts into reusable, data-driven Vue components.

### Compatibility

- Node.js 20.19 or later.
- Modern browsers supporting CSS transforms, filters, and ES modules.
